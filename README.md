## 📖 Sobre Mim

* 👨‍💻 **Desenvolvedor de Software Full Stack** com sólida atuação na criação de APIs RESTful escaláveis, microsserviços e interfaces web modernas, reativas e responsivas.
* 🎓 **Formação Acadêmica e Técnica:**
  * Bacharel em **Sistemas de Informação** pela Universidade Estácio de Sá.
  * Técnico em **Desenvolvimento de Sistemas** pela FAETEC.
  * Extensão em **Desenvolvimento Web com Python** pela Faculdade Senac.
  * Formação intensiva nos bootcamps de **JavaScript e Java Full Stack** pela [Generation Brasil](https://brazil.generation.org/).
  * Participante ativo de acelerações no programa **Oracle Next Education (ONE) + Alura** e **Digital Innovation One (DIO)**.
* 👀 Apaixonado por **games, hardware e tecnologia**, sempre buscando compreender o funcionamento do software desde o nível algorítmico até a arquitetura em nuvem.
* 🚀 Comprometido com o aprendizado contínuo, boas práticas de engenharia de software, código limpo (*Clean Code*) e arquitetura desacoplada.
